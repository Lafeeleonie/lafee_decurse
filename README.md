# lafee_decurse

Préparation d’un futur addon World of Warcraft destiné à assister les joueurs dans la dissipation des effets négatifs.

État actuel : structure initiale uniquement. Aucune fonctionnalité ni fichier Lua n’est chargé par le fichier `.toc`.

## Compatibilité

- Interface WoW : `120100` (12.1)
- Localisations préparées : deDE, enUS, esES, esMX, frFR, itIT, koKR, ptBR, ruRU, zhCN et zhTW.
